# 💼 Данные для Портфолио

Этот файл является источником данных для проектов, отображаемых на сайте.

## 📝 Список проектов

### 1. CoinLover
- **Категория:** Mobile App
- **Описание:** Универсальный трекер личных финансов с глубокой аналитикой в реальном времени.
- **Ссылка:** [coinlover.ru](https://coinlover.ru/landing)

### 2. Baonline
- **Категория:** Web Platform
- **Описание:** Масштабируемый сервис для международного сообщества релокантов. Магазины, автосбор новостей.
- **Ссылка:** [bao.reloto.ru](https://bao.reloto.ru)

### 3. NewAddress
- **Категория:** Web App
- **Описание:** MVP-витрина и система управления недвижимостью для кратковременной аренды.
- **Ссылка:** [reloto.ru/na](http://reloto.ru/na)

### 4. RAG Online
- **Категория:** Web App
- **Описание:** AI-автоответчик для автоматизации малого бизнеса и коммуникаций в «одну кнопку».
- **Ссылка:** [rag.reloto.ru](https://rag.reloto.ru)

### 5. RAG Search
- **Категория:** Web App
- **Описание:** Интеллектуальный контекстный поиск по вашим файлам и документам на базе AI.
- **Ссылка:** [search.reloto.ru](https://search.reloto.ru/)

## ➕ Как добавить новый проект
Чтобы добавить новый кейс:
1. Добавьте его в список выше в этом файле.
2. Обновите массив `projects` в файле `src/components/Portfolio.astro`.
3. Доступные категории: `Mobile App`, `Web App`, `Automation`, `AI System`, `SaaS`.
