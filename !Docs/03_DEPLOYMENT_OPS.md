# 🚀 Деплой и Операции

## 💻 Локальная разработка
1. Установите зависимости: `npm install`
2. Запустите dev-сервер: `npm run dev`
3. Сборка проекта: `npm run build`

## 📦 Контейнеризация (Docker)
Проект запускается в Docker-контейнере (nginx:alpine) под не-root пользователем `nginx` для безопасности.
- **Порт хоста:** 8020
- **Порт контейнера:** 8080

## 🚀 Процесс деплоя
Для обновления сайта на сервере используется скрипт автоматизации `./deploy.sh`.

**Что делает скрипт:**
1. Пушит изменения в ветку `main`.
2. Подключается к VPS по SSH.
3. Делает `git pull`.
4. Пересобирает и перезапускает Docker-контейнер.

**Команда:**
```bash
./deploy.sh
```

## 🌐 Серверная конфигурация (VPS)
- **Host:** server.reloto.ru
- **Nginx:** Настроен как Reverse Proxy с SSL (Certbot).
- **CSP:** Политики безопасности настроены в `nginx.conf` внутри репозитория. При добавлении новых источников (шрифты, скрипты) необходимо обновлять этот файл.
